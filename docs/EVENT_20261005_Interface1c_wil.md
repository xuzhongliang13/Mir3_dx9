# 事件记录：Interface1c.wil 被替换导致登录/选人界面图库异常（2026-10-05）

## 现象
- 登录页（公告页）输入框位置渲染成黑色块，按钮文字（连接游戏/创建账号/修改密码）消失
- 选人界面图库错乱/人物显示异常
- 用户反馈："图库又出问题了"、"登录页面 选人界面都出问题了"

## 排查过程
1. 回退代码到 913305c 后现象依旧 → 排除最近代码改动（诊断日志）影响
2. 检查 D:\Client\Data 下所有 wil 资源时间戳：
   - 绝大多数 wil/wix 为 2005-2020 年原版
   - **唯独 Interface1c.wil / Interface1c.wix 时间戳为 2026/10/5 23:10:17** → 该文件当天被手动替换过
3. 帧布局验证（wix 位置表 + 帧头）：
   - 登录输入框帧2（_LOGINIMG_IDPW）：328x20，两版本尺寸一致
   - 按钮帧10/12/14/16（连接游戏/创建账号/修改密码）：96x24/96x26，两版本尺寸一致
   - 但被替换版帧数据偏移整体多出 8586 字节（文件大小 23,815,990 vs 正常版 23,807,404）→ 帧内容/数据区异常

## 根因
D:\Client\Data\Interface1c.wil 被替换成帧数据偏移异常的版本（文件大小与正常版差 8586 字节），
客户端按原帧号取图时取到错误/空数据：输入框取到黑块、按钮文字取不到、选人界面图错乱。

## 解决
- 备份异常文件：Interface1c.wil.bak_20261005_2310 / Interface1c.wix.bak_20261005_2310
- 用 D:\Mir3G_2007\Data\Interface1c.wil/wix（帧布局验证一致）替换
- 用户实测：登录框正常、按钮文字恢复、选人界面恢复 ✅

## 教训
- 客户端运行目录 D:\Client\Data 的资源文件属于运行环境，不在 git 仓库内，替换需谨慎
- 更换 wil 资源前应先验证帧布局（wix 位置表 + 关键帧尺寸）与客户端代码帧号引用一致
- 若再遇到"图库异常"，先检查资源文件时间戳是否异常（非原版年代）
